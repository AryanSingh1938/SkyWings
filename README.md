# Flight Booking

Flight Booking is a full-stack travel booking application that lets users browse flights, create accounts, and reserve trips with a clean React frontend and Express/MongoDB backend.

## Features

- User authentication and account management
- Flight listings and booking workflow
- Responsive UI for booking travel itineraries
- REST API for secure flight and reservation operations

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB with Mongoose

## Project Overview

This application is designed to simulate a modern flight booking platform, combining user management, booking logic, and a streamlined travel experience in a single project.
